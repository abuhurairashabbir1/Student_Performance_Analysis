## Project Description

This project analyzes the Students Performance in Exams dataset using Python.
The analysis includes descriptive statistics, data cleaning, exploratory data analysis, and data visualization.

## Dataset

* **Name:** Students Performance in Exams
* **Source:** Kaggle
* **File:** data/StudentsPerformance.csv
* **Columns:** gender, race/ethnicity, parental level of education, lunch, test preparation course, math score, reading score, writing score
